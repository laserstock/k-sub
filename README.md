# k-sub — Seoul Subway Exit Guide

외국인 관광객용 지하철 출구·경로 안내 (Next.js + Supabase).

## 앱 위치
실제 코드는 **`k-sub/`** 폴더에 있습니다.

## 미리보기가 안 보일 때 (초보)
이 Project 채팅에 이렇게만 보내세요:

> 사이트 다시 켜줘

자세한 안내: Context의 `docs/how-to-restart.md`

## 직접 실행
```bash
cd k-sub
npm install
npm run dev
```

## 인터넷에 올리기 (Vercel)
초보용 단계별 안내: Context의 `docs/deploy-vercel.md`  
요약: Vercel에서 GitHub로 로그인 → 저장소 Import → **Root Directory = `k-sub`** → Supabase 환경변수 2개 추가 → Deploy.
